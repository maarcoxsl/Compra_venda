# Sistema de Compra e Venda de Ações

Sistema em desenvolvimento para compra e venda de ações na bolsa (ex: Vale, Itaú, etc.).

> **Status atual:** Em desenvolvimento ativo  
> Ainda não está pronto para uso em produção.

## 📋 Sobre o Projeto

Este projeto tem como objetivo permitir que o usuário compre e venda ações de forma simples.  
No momento, o sistema está em fase inicial de desenvolvimento.

## ⚠️ Estado Atual e Limitações

### O que já funciona
- Compra de **uma única ação** por operação

### Limitações conhecidas
- **Não é possível comprar múltiplas ações diferentes** na mesma operação  
  Exemplo: não é possível comprar uma ação da Vale + uma ação do Itaú ao mesmo tempo.
- Existe um **bug no cálculo do preço final**: o valor está sendo acumulado incorretamente na hora de exibir o preço total.

## 🛠️ Em Desenvolvimento

- Correção do bug de acumulação do preço final
- Suporte à compra de múltiplas ações diferentes
- Funcionalidade de venda de ações
- Melhorias de usabilidade e interface
